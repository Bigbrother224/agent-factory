# Axe : AI Automation & Systems

Outils, orchestrateurs et infrastructures qui rendent les systèmes IA autonomes :
agents, pipelines d'automatisation, orchestration multi-agents, glue système,
observabilité d'agents, self-hosting d'IA.

**Un projet de cet axe doit montrer** : de l'ingénierie système réelle (process,
concurrence, APIs, sandboxing, CI), pas un simple script autour d'une API LLM.
