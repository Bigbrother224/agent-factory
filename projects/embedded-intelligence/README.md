# Axe : Embedded Intelligence

L'IA et l'intelligence qui descendent dans le matériel : embarqué (ESP32,
Raspberry Pi, microcontrôleurs), edge ML, passerelles matérielles, perception
capteurs, robotique logicielle, matériel + IA combinés.

**Un projet de cet axe doit montrer** : du code qui touche du matériel réel
(ou émulé sérieusement), des contraintes embarquées assumées (mémoire, latence,
énergie), et une démo vérifiable.
