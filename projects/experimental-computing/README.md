# Axe : Experimental Computing

Informatique expérimentale : nouveaux langages, paradigmes inhabituels,
calcul non conventionnel (cellulaire, analogique, quantique simulé),
visualisations algorithmiques, art génératif algorithmique, preuves ludiques.

**Un projet de cet axe doit montrer** : une idée technique originale poussée
jusqu'à une démonstration — pas une collection de notebooks.
